# Freedom CQA

Интерактивный каркас веб-сервиса Conversation Quality Analytics для хакатона.

## Запуск

Нужен Node.js 20 или новее. Устанавливать зависимости не требуется.

    node server.mjs

Откройте http://127.0.0.1:4173. Для другого порта задайте переменную PORT.

## Что работает

- Обзор с показателями, рассчитанными из текущих данных.
- Поиск, фильтры RU/KZ/EN, фильтры статуса и сортировка.
- Карточка диалога с транскриптом, оценками и подсветкой реплик-доказательств.
- 8 исходных критериев из чек-листа, редактирование и добавление критериев.
- Версии чек-листа: старые оценки сохраняют снимок исходных правил.
- Апелляция, решение проверяющего, исходная и финальная оценка.
- Пересчёт весов, числовых шкал и N/A; грубые ошибки учитываются отдельно.
- Импорт JSON в формате API организаторов, ссылки на записи звонков.
- Экспорт JSON с исходными и финальными результатами.
- Сохранение рабочего состояния в localStorage этого браузера.

## Границы прототипа

AI API ещё не подключён. Восемь демонстрационных диалогов созданы для проверки интерфейса, шесть имеют заранее заданную разметку. Они явно обозначены как примеры и не являются набором DEV или результатами AI.

Импортированные диалоги остаются без оценки. Каркас не выдаёт готовую демооценку за анализ нового текста. Хранение локальное, без общей серверной базы и без синхронизации между пользователями.

## Структура

- dist/index.html — точка входа.
- dist/app.js — интерфейс, навигация, импорт, апелляции и локальное состояние.
- dist/domain.js — типы данных в форме объектов, чек-лист, формула и демопримеры.
- dist/styles.css — визуальная система и адаптивные размеры.
- server.mjs — локальный сервер, без зависимостей.
- checks/scoring.test.mjs — проверки формулы и ссылок доказательств.

## Следующий этап

Подключить серверный endpoint оценки и OpenAI API. Ключ должен храниться на сервере. Передавать модели выбранную версию чек-листа и транскрипт, проверять формат ответа и ID реплик. Итоговый балл продолжает рассчитываться обычным кодом. Деморазметку не использовать как оценку импортированных диалогов.

Далее: настоящий DEV API, серверное хранение, обработка ошибок и повторов, сравнение с ручной разметкой по языкам.

## Визуальное направление

Референс: https://fbroker.kz/ — официальный сайт Freedom Инвестиции.
Светлые поверхности, зелёный акцент, тёмно-зелёный блок, округлые карточки.
Логотип загружен с https://fbroker.kz/images/Logo.svg и сохранён без изменения пропорций.
Используется Manrope с Google Fonts и системный запасной шрифт Segoe UI.
Это прототип для хакатона, не официальный продукт Freedom.

## Приватная демонстрация

Опубликованная версия использует тот же статический интерфейс. Данные сохраняются в браузере посетителя; исходные файлы транскриптов не отправляются на AI-сервис.
